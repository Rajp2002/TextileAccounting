# UX-012 — Factory-Facing Terminology Inventory

Prepared: 2026-07-14 IST

Status effect: **none**. `UX-012` remains `BLOCKED` until a named pilot-factory supervisor completes and dates the decision pack.

## Method and coverage

This inventory was built from the current owner and supervisor routes, localized dictionaries (`en`, `hi`, `gu`), validation schemas/messages, mobile production and worker screens, generated payslip/WhatsApp text, data export keys, current operator documentation, and the canonical UX row. It inventories business concepts rather than every repeated occurrence of the same literal.

Representative surface groups inspected:

- Owner: Factory Today, estimator, quotes, orders, market runs, looms, workers, payroll, advances, stock, commercials/ledger, dispatches, analytics, settings/export, archive.
- Supervisor/mobile: shift-meter entry, looms/assignments, workers, Kharchi, attendance, offline/update messages.
- Generated output: PDF payslips, WhatsApp payroll summaries, settings data export, dispatch/challan references.
- Documentation: current onboarding, feature guides, grey-fabric workflow analysis, pilot runbooks, and user-facing landing copy.

Locations below are the shortest reproducible route and principal source locations. A reviewer should use the screenshot instructions in `UX-012_TERMINOLOGY_DECISION_PACK.md` for visual context.

## Highest-risk mismatches found

1. **Loom versus machine:** English factory navigation uses Looms; Hindi/Gujarati and several assignment/validation strings use machine.
2. **Shift total versus counter reading:** quick production entry is a shift total, while historical/schema terms still contain opening/closing meter-reading language.
3. **Quality versus market run/order:** “quality”, “fabric label”, “run”, and “active order” appear around the same selector but are different concepts.
4. **Upaad versus Kharchi:** both involve cash, but only Upaad is a worker debt/recovery concept; Kharchi is supervisor-float activity.
5. **Taka/roll/package/bale:** these labels are treated as configurable/interchangeable in places although physical meaning may differ.
6. **Sold/sent/received metres:** three distinct quantities affect stock, receivables, shortages and claims.
7. **Metres and kilograms:** `m`, `mtrs`, meter/metre, `m/kg`, `kg/100m`, `₹/m`, and `₹/kg` vary across UI, validators and generated output.
8. **Party ledger versus Commercials:** the same money workflow is exposed under accounting, commercial and factory-floor language.
9. **UI versus generated output:** PDF payslips and data-export keys use English/developer labels even when Gujarati/Hindi UI is selected.

## Pre-approval change decision

No product text was changed during this preparation sprint. The observed inconsistencies are intertwined with genuine factory-language choices, financial meanings, or unit conventions; treating them as “obvious typos” would silently make the supervisor’s decision. Internal database/code identifiers are also intentionally unchanged because renaming them would add migration risk without improving the pilot UI.
