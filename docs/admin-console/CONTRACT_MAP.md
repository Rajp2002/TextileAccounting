## Current product decisions resolved from source

- **Factory key:** `organizations.id` is the tenant key. `app/(auth)/actions/auth.ts:createOrganization` stores `factoryName` as `organizations.name` and owner profile `org_id`. Billing foundation explicitly says org ID, not factory ID. This supports one organization as one factory in this source model; real business mapping and production cohort classification still need owner evidence.
- **Support intake:** current Base operations are owner-only; supervisors are archived (`lib/phase1-scope.ts`, role-home routing). Implement authenticated current owner intake with verified org/profile independently of plan and write lock, requester-only visibility, no SLA/channel automation, in-app delivery.
- **Access:** use `resolveEffectiveSubscription`, `hasPaidBaseHistory`, `hasEstablishedPaidHistory` and explicit Free grants at a shared snapshot; active/grace current access differs from paid term. An expired paid Base account can retain Lite. Failed latest checkout cannot obscure earlier access. Missing subscription is not Free.
- **Free:** policy version 2 uses two new costings per India calendar month (`20260912130854_free_monthly_allowance.sql`). October 4 migration `20261004090000_free_monthly_period_end_local_month.sql` calculates end in the policy local zone; do not add a UTC month to a zoned instant. Quota rows key the owner subject, grants may span orgs. Saved original costing has verified org attribution; raw funnel events do not. Same-entry recalculation until original creation + 30 minutes updates revision and does not debit (`20261004093000_free_costing_recalculation_window.sql`); creation time never resets. `FREE_COUNTING_CONTRACT` is older reference wording: authoritative recalculation SQL/window wins.
- **Base first useful production:** current `saveBaseDailyProductionBatch` writes through `save_base_daily_production_reviewed` and validates dated worker/machine/job setup. `20260903155014_base_production_machine_register.sql` joins active dated worker-machine assignments, active machines, non-cancelled job contexts; the underlying writer validates same-org workers and allocation snapshots. Count a persisted valid production outcome, not all modules/payroll onboarding. Blank/absent/zero register rows are not automatically a meaningful production milestone. Use `base_daily_production_entries`/batches for this path, not only legacy `production_logs` or `base_production_entries`.
- **Billing:** `lib/billing-constants.ts` confirms Lite ₹2,999/₹1,499 and Base ₹9,999/₹4,999, recorded paise including GST; 365-day terms; same-plan manual renewal final 30 days/after expiry. No pricing or access policy change. Readiness blocks live while document policy is `not_supported`; show sanitized readiness, do not enable it.
