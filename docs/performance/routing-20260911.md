# Routing performance — 11 September 2026

The patch improves navigation feedback, Free-route streaming, and client-side work during page changes. This report records local verification before release; the JSON's deployment flag describes that capture time. Baseline: `2f6fd4fdb461249a7f56f4f61d652cba8d684390`.

## Changes

- Owner, Free, and supervisor navigation now use a small shared `NavigationLink` with Next's `useLinkStatus`. A pending destination gets a subtle overlay after 100 ms. Fast transitions avoid a flash; reduced-motion users receive static feedback. The overlay cannot intercept clicks, so another destination remains selectable. Current primary links expose `aria-current`.
- Free estimator, saved costings, account, and billing have loading boundaries. Their fallbacks show the destination's title while data is still loading. Default Next partial prefetching is retained. No full-route prefetch loop or new business-data cache is added. This follows [Next's navigation guidance](https://nextjs.org/docs/app/getting-started/linking-and-navigating).
- Seven Orders links and two Payroll navigation actions now use client-side routing instead of full-document navigation. The legacy supervisor production alias redirects on the server, removing its intermediate client render and effect.
- Navigation color transitions last 150 ms instead of 300 ms on mobile and no longer animate every CSS property. Drawer closing uses `onNavigate`, preserving ordinary modified-click behavior.
- The legacy language localizer does no DOM scanning or mutation observation while English is active. Switching back from Hindi/Gujarati restores translated text and attributes once, releases the tracked originals, and disconnects. Non-English mutation localization remains active.

## Reproduction and scope

Run `node scripts/performance/routing-fixture.mjs 2f6fd4fdb461249a7f56f4f61d652cba8d684390`, then the printed build/start commands. The generator creates a temporary Next app, reuses installed packages, and copies the relevant real source. `/before` uses the original English localizer; `/free` uses the optimized one. Each synthetic dynamic page waits 1,200 ms. `/slow` deliberately has neither a loading boundary nor prefetch, so the pending-link state can be inspected. Use the language buttons and Add rows to inspect `window.routingMetrics`, and the shared input to check state preservation across navigation.

The application build ran through `node scripts/performance/isolated-command.mjs npm run build`, isolating it from configured remote service credentials. No dependency, database, authorization, entitlement, service-worker, document-cache, or deployment settings changed. Authenticated production route timings and installed-PWA/device testing remain unmeasured; this report makes no production speedup claim.
